积分是 Vidoc Note 的计量单位：**生成一条摘要消耗一次积分，扣多少取决于视频时长**。注册即赠送 100 永久积分，可以先免费体验。

## 计费规则：按视频时长阶梯

| 视频时长 | 消耗积分 |
| --- | --- |
| 10 分钟以内 | 10 分（起步价） |
| 11 ～ 60 分钟 | 每分钟 1 分（60 分钟 = 60 分） |
| 61 分钟 ～ 3 小时 | 60 分 + 超出 60 分钟的部分每分钟 1.5 分（2 小时 = 150 分，3 小时 = 240 分） |
| 超过 3 小时 | 直接拒绝，**不消耗积分** |

两个细节：

- 扣分发生在**读到视频时长之后**。所以提交时不会预扣，只有确认时长在范围内才扣。
- 阶梯只作用于超出部分，档位之间连续：60 分钟是 60 分，61 分钟是 62 分，不会突然跳档。

## 积分从哪来

| 来源 | 说明 |
| --- | --- |
| 注册赠送 | 新用户注册即赠送 **100 永久积分**。 |
| 充值 | 一次性购买，**永久有效**，可以重复购买。 |
| 订阅 | 订阅套餐**按期到账**，当期未用完不结转到下期。 |
| 失败退回 | 生成过程中失败时，这次扣掉的积分按原分项自动退回。 |

永久积分（注册赠送、充值、失败退回）不会过期；订阅积分只在订阅有效期内可用。

## 什么情况会退积分

- **生成失败**：解析到时长并扣分之后若发生失败（例如没有可用字幕、模型调用失败），已扣积分会**自动原额退回**，不需要联系客服。
- **时长超限、链接无效、无法解析视频**：这些检查发生在扣分之前，所以压根不会扣。
- **服务器繁忙被拒绝**：请求排队已满时任务会被直接拒绝，也不会扣分，稍后重试即可。

已经成功生成并交付的摘要，所消耗的积分**不支持退款**（详见[服务条款](/terms)）。
