## 第一步：粘贴视频链接

打开 [vidocnote.com](/)，在首页输入框里粘贴 **Bilibili 视频页链接**（形如 `https://www.bilibili.com/video/BVxxxxxxxxxx`）。

链接必须以 `http://` 或 `https://` 开头。如果粘贴的是分享文案，只保留其中的链接部分。

## 第二步：点击「生成摘要」

未登录时会先弹出登录框。Vidoc Note 用**邮箱 + 密码**登录，不需要手机号：

- 邮箱**没有注册过**：输入邮箱和密码即会自动创建账号，无需单独的注册流程。
- 邮箱**已经注册过**：输入原来的密码登录；忘记密码时可通过同一邮箱重新登录同一条账号数据（账号与邮箱一一对应）。

登录状态保持 7 天，过期后重新登录即可。

## 第三步：等待三步生成流程

提交后，页面上的进度终端会依次显示三个步骤：

1. **解析视频信息** — 读取视频标题、UP 主、时长与封面。
2. **获取并解析字幕** — 抓取该视频的字幕文本。
3. **生成 Markdown** — 把字幕交给大语言模型，产出结构化摘要。

整个过程通常需要**十几秒到几十秒**，取决于视频长度与排队情况。生成期间可以离开页面，任务在服务端继续；也可以点终端右上角的按钮停止当前等待并清空终端。

## 第四步：查看与保存摘要

生成完成后：

- 摘要卡片直接显示在首页下方，按 Markdown 渲染（含标题层级与列表）。
- 地址栏会变成带 `?id=` 的地址，可以刷新、收藏或稍后再打开。
- 摘要同时写入你的**历史记录**（顶部导航「历史记录」），随时可以回来查看或删除。

摘要只对你本人可见：换成其他账号打开同一个链接拿不到内容。

## 生成失败怎么办

失败时页面会弹出「生成失败」并附上原因，例如「该视频没有可用字幕，暂不支持生成摘要」。这次生成**不会扣掉你的积分**（已扣的会自动退回），换一条视频重试即可。详见[故障排查](/docs/reference/troubleshooting)。
