**Vidoc Note（vidocnote.com）是一个在线 AI 视频摘要工具**：把视频链接粘贴进去，它会抓取这个视频的字幕文本，交给大语言模型生成一份结构化的中文详细摘要，并把摘要保存在你的账号里，随时可以回看或删除。

和「看一遍再说」相比，它把 1 小时的视频压缩成几分钟能读完的重点笔记；和纯语音转写工具相比，它输出的是经过归纳的结论与要点，而不是逐字稿。

## 它能做什么

- 从视频链接自动获取视频信息（标题、UP 主、时长、封面）。
- 抓取视频的字幕文本（人工字幕或平台自动字幕）。
- 生成结构化的 Markdown 摘要：先给结论，再分节展开要点。
- 把摘要保存到你的账号，在「历史记录」里随时查看、删除。

## 它暂时不能做什么

| 限制 | 说明 |
| --- | --- |
| 只支持 Bilibili | 目前仅支持 Bilibili 视频，其他平台还在开发中。 |
| 必须有字幕 | 依赖视频自带字幕，暂不支持语音识别（ASR），没有字幕的视频无法生成摘要。 |
| 单条视频上限 3 小时 | 超过 3 小时的视频会被直接拒绝，且不消耗积分。 |
| 摘要由 AI 生成 | 可能存在错漏或过度概括，重要内容请回到原视频核对。 |
| 不下载视频本体 | 只处理字幕文本，不保存视频文件。 |

## 三步上手

1. 打开 [vidocnote.com](/)，把 Bilibili 视频链接粘贴到首页输入框。
2. 点击「生成摘要」。如果还没登录，会先弹出登录框：输入邮箱和密码即可，未注册的邮箱会自动创建账号，不需要单独注册流程。
3. 等待进度终端走完「解析视频信息 → 获取并解析字幕 → 生成 Markdown」，摘要卡片就会出现。

新用户注册后赠送 **100 永久积分**，足够先免费体验几条短视频摘要。
